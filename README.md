# 🛒 Chat2Order

Chat2Order é uma extensão para Google Chrome que permite importar conversas e transformá-las em pedidos estruturados, exibindo-os em uma interface moderna dentro do **Side Panel** do navegador.

O projeto é construído com:

- ⚡ Vite
- ⚛ React
- 🔷 TypeScript
- 🎨 Tailwind CSS
- 🧩 Manifest V3 (Chrome Extension)
- 🪟 Side Panel

---

## 🚀 Objetivo

A extensão possui um fluxo simples:

1. O usuário clica em **Importar Conversa**
2. O sistema processa os dados (atualmente mockados)
3. O pedido formatado é exibido na tela
4. O usuário pode acessar o **Dashboard externo** para visualizar todos os pedidos

A arquitetura foi pensada para ser escalável, permitindo futura integração com API real.
